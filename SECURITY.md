# Security policy

## Supported versions

The current v1 development line is supported. Older versions are not supported. Until a first release is published, report issues against the current default branch.

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues. Email **security@example.com** (placeholder; replace this address before publishing) with a description, affected version or commit, reproduction steps, and potential impact. Do not include real resident data, passwords, signing keys, or access tokens in a report.

The maintainers will acknowledge reports and coordinate a fix and disclosure. Please allow time for a fix before publicly disclosing a vulnerability.
